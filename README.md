# BlueAnt CRM ERP

BlueAnt CRM ERP is a production-ready CRM and ERP application built with **Java 21**, **Spring Boot**, **Spring Security**, **JWT Authentication**, **MySQL**, and **Maven**.

## Features

- JWT Authentication & Authorization
- Lead Management
- Meeting Workflow
- Follow-up Management
- Dashboard
- REST APIs

## Tech Stack

- Java 21
- Spring Boot 3
- Spring Security
- MySQL
- Spring Data JPA
- Maven

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Blueantfinserv/blueant-crm-erp.git
```

Run the application:

```bash
mvn spring-boot:run
```

Swagger UI:

```
http://localhost:8080/swagger-ui/index.html
```
